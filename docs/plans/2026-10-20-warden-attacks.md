# Warden fights: read, defend, punish

User direction: wardens need distinct attacks that can be dodged and countered, not just more required hits. Lesser demons remain quick. Original enemy names, attacks, timings and rewards are game fiction; scripture still guides imagery, not these mechanics.

The Rift lancer coils into a red arrow lane, tracks briefly then commits before launch. Its rush is unblockable; move sideways or leave its lane. It does not home after commitment. A missed rush leaves a gold recovery opening. The Cinder cantor raises both hands, commits an amber aim and releases three separate darts. Move off that aim or face them with the shield. Raising the shield in the280ms before actual contact interrupts the volley and exposes the cantor immediately. Holding the shield still blocks, but does not grant a timed parry.

A successful defense exposes the enemy for2.4 seconds. The usual tap/click/Chain sword strike can then shatter all remaining armor and bind it. Credit requires physical sword contact, valid range/LOS/path and a real launch. The opening can be reserved by a launched dive, while cancellation drops the reservation. Ordinary attacks still chip armor; rebuke interrupts. A first attack requires a deliberate visible low-speed face-off (0.65s below10m/s), or a sword hit that provokes retaliation; a fast fly-through alone does not invite a rush. One warden takes a turn at a time; normal dart scheduling waits through the elite turn. Nothing stops player movement or adds a camera writer.

Rush movement and darts test fixed geometry; relative swept contact covers moving players and dropped frames. The lancer overshoots by only3m so recovery stays reachable in portrait. Tells use arrows, poses and text as well as color. Reduced motion holds decorative size changes steady. Transient state stays outside React, rendering uses three owned pooled draws, audio reuses the existing capped/muted bus.

The independent generic Arkham counter branch e908082 was accepted elsewhere but is not merged here. This branch changes enemy-specific recovery/parry behavior through normal sword input and avoids that branch’s claimed files. Integration must check how its global counter target selection interacts with elite guard windows. This is an isolated preview until cross-review.

Phone defense buttons appear only during that warden’s active attack: hold Evade left/right for the lancer, or Hold shield for the cantor. They request the existing strafe/shield intents; Player remains the movement writer. Pointer release/cancel/lost capture, blur, attack end and unmount release the owned input. Keyboard Space/Enter also work on focused defense controls. A visible elite duel holds new lesser-dart scheduling through the finisher, so offscreen darts do not ambush a focused counter. Leaving its range or defeating it restores the ordinary schedule.
