# Release gates requiring physical review

These are explicit limitations of the playtest candidate, not completed checks.

| Gap | Affected users | Owner | Mitigation | Target |
|---|---|---|---|---|
| Physical Mac trackpad feel in Safari and Chrome: acceleration, natural-scroll direction, trusted momentum tagging, capture/release and wheel delivery while captured, edge steering, native pinch, and click/drag comfort | Desktop trackpad players | Garo as tester; Codex handles tuning | A/B steering comparison, bounded speed, click-to-hover, interruption braking, local gesture recording, optional mouse/keyboard and tap controls; system-Chrome pointer/wheel regression tests. Browsers without momentum tagging use a conservative quiet-window gate that needs physical tuning. | First trackpad playtest after delivery; before public launch. Browser automation is not a physical finger test. |
| Physical iPhone 15-or-newer Safari performance, heat, one-thumb ergonomics, long-press selection suppression and actual orientation changes | Mobile players | Garo as device tester; Codex handles fixes | Low graphics tier, touch/browser regression tests, downloadable timing report | First on-device review after delivery; before public launch. Date depends on device-test availability. |
| VoiceOver and physical iPhone Safari zoom/contrast checks | Screen-reader and low-vision users | Codex with device tester | Native HTML guide and dialogs, keyboard controls, reduced camera motion, automated AA scans | First accessibility device review; before public launch. |
| Subjective comfort, visual quality and enjoyment | All players | Garo and Codex | Small replayable route, camera/quality choices, easy pause and reset | First playtest feedback cycle. |
| Active flight uses `touch-action: none` to distinguish independent movement/look fingers from browser pinch. In-flight native zoom requires pausing first. Physical Safari handoff, zoom after pause, finger crossing and accidental-contact ergonomics remain unverified. | Mobile players, including players needing magnification | Codex with Garo as device tester | Native pinch in paused UI/guide; no viewport zoom restriction; keyboard and single-tap alternatives; automated real Chrome touch sequences | First Safari review after this revision; before public launch. |
| Suit blaster on iPhone Safari, portrait and landscape: two-thumb Fire plus a flight thumb in both orders (Safari fires `gesturestart` for any second finger; the zoom reset is desktop-only and Chromium specs cannot see this path); Fire and Aim reach; edge back/forward and home-indicator swipes near Fire; `pointercancel` timing; audio unlock, the playback audio session and the silent switch; safe-area insets; 60 fps, and 30 fps in Low Power Mode. **NOT validated.** | Mobile players | Garo as device tester; Codex handles fixes | Chromium touch specs in both orientations, extended hit boxes 24 px from the edges, clears on pause/resize/rotation/cancel, tap-control Fire and Aim toggles | First shooter device review; before merging `codex/shooter`. Emulation is not iPhone validation. |
| Twin-stick touch controls and browser protection (2026-09-24, `docs/touch-controls.md`), iPhone Safari, both orientations: left-edge back swipe during a stick drag shows the Leave card and does not exit; portrait stick drag near the bottom bar does not switch tabs; home swipe and return comes back paused; Control Center or Notification Center pull releases input without pausing; no zoom from a two-thumb pinch in play, pinch zoom on the pause card; Resume while zoomed resets or shows the zoom note; toolbar show/hide mid-drag keeps the stick; rotation mid-drag keeps playing, re-anchored; no loupe or callout on a 3 s Fire hold; 5 fingers held, a sixth cancels without a pause; hold Descend to land; level flight feel; tapping the edge of Pause; 2 min cruise with no auto-lock; Add to Home Screen full screen; Screen diagnostics values; thumb reach and sizes. **NOT validated.** | Mobile players | Garo as device tester; Codex handles fixes | System Chrome CDP touch specs (routing, 5-finger ownership, cancel-all, blur without pause, toolbar resize, rotation, fit matrix, pause-card fit, zoom guard, history sentinel, axe in both orientations); Playwright WebKit for `gesturestart` only when already installed; Screen diagnostics in Flight settings for reading real values | First device review of the new touch controls; before merging `codex/shooter`. Emulation is not iPhone validation. |
| Drone readability at 15-60 m (eye halo floor 10 CSS px). **NOT validated.** | All players, low-vision players | Garo and Codex | Halo size floor, amber rim light, alert colour change | First shooter playtest. |
| Dodge reaction time, muted and in landscape (telegraph ring plus HUD chevron). **NOT validated.** | All players, deaf and hard-of-hearing players | Garo and Codex | Visual telegraph ring and crosshair chevron as well as the chirp; tutorial drone never dodges before the first kill | First shooter playtest. |
| Mac trackpad click-hold comfort for C/Q fire and aim. **NOT validated.** | Desktop trackpad players | Garo as tester | Keys never change click or scroll meanings; mouse mode offers left/right click | First trackpad playtest with the blaster. |
| The throttled 'Drone down' live-region announcement with VoiceOver. A deterministic browser kill was not achieved (the tutorial drone alerts and orbits from a load-timing-dependent anchor), so the announcement itself is untested in any browser. **NOT validated.** | Screen-reader users | Codex with device tester | Live region outside the aria-hidden HUD; a browser spec checks its placement | First accessibility device review with the blaster. |

The release date is not set. Do not describe this preview as fully accessibility-certified or iPhone-performance-validated.
